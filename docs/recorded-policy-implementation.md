## Application workflow

Open Administration > Approved Rules & Catalogue. The recorded review-pack panel displays the date, missing reviewer name, numerical definitions, source register and research pricing records. Create Pending Rule Versions assigns the next available version for each variety and creates both definitions in one transaction. Repeating the operation reuses existing source imports; source content is fingerprinted and changed content cannot overwrite an earlier import. Actor IDs and audit entries come from the authenticated administrator.

A different administrator can inspect and activate a pending version using the existing review workflow. Domain-source approval and independent system activation are separate records. If an imported draft is subsequently edited, its source attribution is marked as no longer applying to the edited definition. No public references are promoted to B2B records by this operation.

## Recorded numerical behaviour

Tone/depth penalties and monetary quality adjustments are disabled. Size is displayed as not graded, including saved summaries, personalised wording and PDF reports. Weight remains part of matching and total-price calculations. Numeric depth placeholders are not presented as ideal proportions.

Matching, minimum evidence, currency, date limits and price-range allowance are exactly those in the recorded candidate. The original research distinguishes these project choices from external standards. Approval does not imply empirical calibration or a confidence interval.

The form now optionally records inclusion type, location and reported durability concerns. These fields are validated and retained in the canonical input and evidence snapshots. They do not add unapproved score deductions or monetary adjustments. A possible durability concern creates a qualified-assessment recommendation. Empty optional observations are not invented for legacy or source records.
